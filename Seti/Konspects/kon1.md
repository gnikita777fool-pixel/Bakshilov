# Конспект лекции №1. Введение в компьютерные сети

---

## 🔹 Основные понятия

| Термин | Определение |
|--------|-------------|
| **Сеть (Network)** | Совокупность взаимодействующих объектов (узлов) |
| **Компьютерная сеть** | Система связанных компьютеров, телекоммуникационного оборудования и ПО для информационного обмена |
| **Узел сети** | Хост или конечная система |
| **Пакет** | Отдельная порция информации, передаваемая по сети |

### Состав компьютерной сети:
- Компьютеры по назначению сети
- Коммуникационное оборудование
- Сетевые ОС (NOS)
- Сетевые приложения

---

## 🔹 Телекоммуникации

**Телекоммуникации** — передача и приём информации (звук, изображение, данные, текст) на расстояние по электромагнитным системам.

### Структура телекоммуникационной сети:
```
Телекоммуникационная сеть
├── Коммуникационная сеть → передача данных
└── Информационная сеть → обработка, хранение, передача + абонентские системы
```

### Состав телекоммуникационных сетей:
1. **Сеть доступа (access network)** — подключение конечных пользователей
2. **Магистральная сеть (backbone)** — высокоскоростная транзитная передача трафика
3. **Информационные центры** — ресурсы для обслуживания пользователей

### Виды телекоммуникационных сетей:
- Компьютерные (данные)
- Телефонные (голос)
- Радиосети (вещание)
- Телеграфные (текст)
- Телевизионные

## 🔹 Классификация сетей

### 1. По территориальному признаку
| Тип | Аббр. | Описание | Пример |
|-----|-------|----------|--------|
| Локальная | LAN | Одно помещение/здание/небольшая территория | Сеть лаборатории, корпуса вуза |
| Региональная | MAN | Район, город, регион | Городская сеть провайдера |
| Глобальная | WAN | Разные города, страны | Интернет, Fido |

### 2. По масштабу подразделения
- Сети отделов/рабочих групп
- Сети кампусов (университет, несколько зданий)
- Корпоративные сети (предприятие)

### 3. По технологии передачи
- **Broadcast** (один-ко-многим, разделяемый канал)
- **Point-to-point** (точка-точка)

### 4. По организации обмена данными
**Сети с коммутацией:**
- Каналов
- Пакетов ⭐ (наиболее распространена)
- Сообщений

> **Коммутация** — выбор маршрута и организация передачи данных при наличии альтернативных путей.  
> **Сетевой трафик** — информационные потоки в сети.

### 5. По типу среды передачи
- **Проводные**: коаксиал, витая пара, оптоволокно
- **Беспроводные**: радиочастоты, ИК-диапазон

### 6. По иерархии компьютеров
| Тип | Описание |
|-----|----------|
| **Одноранговая (P2P)** | Все узлы равноправны |
| **Клиент-серверная** | Есть выделенный сервер, предоставляющий услуги клиентам |

> **Сервер** — компьютер/программа, предоставляющая услуги.  
> **Клиент** — компьютер/программа, запрашивающая услуги.  
> **Распределённая программа** — состоит из частей, выполняющихся на разных компьютерах.

## 🔹 Назначение компьютерных сетей

### Основные цели:
1. ✅ Доступ к разделяемым ресурсам
2. ✅ Межперсональная коммуникация

### Услуги доступа к ресурсам:
- Удалённый вход (Remote Login)
- Передача файлов (File Transfer)
- Удалённый вызов процедур (RPC)
- Совместное использование устройств

### Услуги коммуникации:
| Услуга | Формат |
|--------|--------|
| Электронная почта | 1:1 |
| Списки рассылки | 1:n |
| Телеконференции | n:n |
| Электронные доски (BBS) | n:n |
| Видеоконференции | n:n |

## 🔹 История развития сетей (хронология)

| Год | Событие |
|-----|---------|
| **1960-е** | Проект DARPA по объединению мейнфреймов; начало пакетных сетей |
| **1969** | Запуск **ARPANET** (Минобороны США) — первая глобальная сеть |
| **1971** | Рэй Томлинсон (BBN) создал первую программу **e-mail** |
| **1973** | Роберт Меткалф (Xerox) предложил **Ethernet** |
| **1974** | Винтон Серф и Роберт Кан разработали протокол **TCP** |
| **1978-79** | Разработка эталонной модели **OSI** |
| **Начало 1980-х** | Создание стека **TCP/IP**; формирование современного Интернета |
| **1988** | Червь Морриса поразил ~6000 узлов ARPANET → создание **CERT** |
| **1980-85** | Стандартизация локальных сетей: Ethernet (1980), Token Ring (1985), FDDI (1985) |
| **Конец 1980-х** | Замена ARPANET на **NSFNet** (National Science Foundation) |
| **1991-92** | Тим Бернерс-Ли (CERN) изобрёл **World Wide Web** |
| **1994** | Создание протокола **PPP** |
| **1995** | Переход к коммерческой инфраструктуре; появление **ISP**; современный статус Интернета |

---

## 🔹 Ключевые выводы

1. Компьютерная сеть — инфраструктура для обмена данными между устройствами.
2. Телекоммуникационные сети включают как каналы передачи, так и информационные ресурсы.
3. Классификация сетей многомерна: по территории, технологии, топологии, среде передачи.
4. Основные функции сетей: **ресурсный шеринг** и **коммуникация**.
5. Современный Интернет — результат эволюции от военных проектов (ARPANET) через стандартизацию (TCP/IP, OSI) к коммерциализации (1990-е).

> 📌 **Запомнить**: Пакетная коммутация + протокол TCP/IP + модель OSI = фундамент современных сетей.
