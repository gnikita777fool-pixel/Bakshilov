Данная лабораторная работа изначально написана для классической командной строки Windows (`cmd.exe`). Git Bash использует синтаксис Unix/Linux, поэтому многие команды заменяются на их bash-аналоги. Ниже приведён полный пошаговый перевод задания на синтаксис Git Bash.

> ⚠️ **Важно:** Перед началом работы откройте Git Bash и перейдите в удобную рабочую папку, например:
> ```bash
> mkdir -p ~/lab_work && cd ~/lab_work
> ```
> Все пути ниже указаны относительно текущей директории.

---

### 🔄 Соответствие команд Windows CMD → Git Bash
| Windows CMD | Git Bash (Linux-стиль) | Примечание |
|-------------|------------------------|------------|
| `md`        | `mkdir`                | `-p` создаёт промежуточные папки |
| `rd`        | `rm -r` или `rmdir`    | `-r` для удаления с содержимым |
| `del`       | `rm`                   |            |
| `ren`       | `mv`                   | Переименование и перемещение |
| `copy`      | `cp`                   |            |
| `cls`       | `clear`                |            |
| `type`      | `cat`                  |            |
| `edit`      | `nano` / `vim`         | `nano` проще для новичков |
| `copy con`  | `cat > файл` или `echo`|            |
| `prompt`    | `export PS1="..."`     | Настройка приглашения |

### 📝 Пошаговое выполнение в Git Bash

#### 1. Создание дерева каталогов в `Temp`
*(Точная структура по вариантам в тексте не указана, поэтому создаём базовую, необходимую для дальнейших шагов)*
```bash
mkdir -p Temp/{A1,A2,Personal,University,Hobby}
```

#### 2. В `A2` создать `B4`, `B5` и удалить `B2`
```bash
mkdir -p Temp/A2/{B4,B5}
# Если B2 уже существует, удаляем его:
rm -rf Temp/A2/B2
```

#### 3. Создание файлов в `Personal`
```bash
echo "Бакшилов Никита Михайлович" > Temp/Personal/Name.txt
echo "31.01.2008" > Temp/Personal/Date.txt
echo "Школа №15, г. Москва" > Temp/Personal/School.txt
```

#### 4. Создание файлов в `University`
```bash
echo "МГТУ им. Баумана, Информационная безопасность" > Temp/University/Name.txt
printf "Математика: 90\nФизика: 85\nРусский язык: 80\nИтого: 255\n" > Temp/University/Mark.txt
```

#### 5. Создание файла в `Hobby`
```bash
echo "Программирование, чтение, туризм" > Temp/Hobby/hobby.txt
```

#### 6. Копирование и переименование в `A2`
*(Замените `1` на номер вашего варианта)*
```bash
cp Temp/Hobby/hobby.txt Temp/A2/Lab_1.txt
```

#### 7. Копия и удаление файла
```bash
cp Temp/A2/Lab_1.txt Temp/A2/copy_Lab_1.txt
rm Temp/A2/copy_Lab_1.txt
```

#### 8. Очистка экрана
```bash
clear
```

#### 9. Вывод содержимого всех файлов `Personal`
```bash
cat Temp/Personal/*.txt
# Или поочерёдно с разделителем:
for f in Temp/Personal/*.txt; do echo "=== $(basename $f) ==="; cat "$f"; echo; done
```

#### 10. Сортировка файлов по имени
В bash `ls` уже выводит по имени. Для явной сортировки:
```bash
ls -1 Temp/Personal/ | sort
```

#### 11. Объединение файлов в `all.txt` и вывод
```bash
cat Temp/Personal/*.txt > Temp/Personal/all.txt
cat Temp/Personal/all.txt
```

#### 12. Редактирование `all.txt` (добавить год рождения)
```bash
# Вариант 1 (быстрый, через консоль):
echo "Год рождения: 2000" >> Temp/Personal/all.txt
cat Temp/Personal/all.txt

# Вариант 2 (интерактивный, аналог edit):
nano Temp/Personal/all.txt
# В nano: допишите строку, нажмите Ctrl+O (сохранить), Enter, Ctrl+X (выход)
```

#### 13. Копирование `all.txt` в `A1`
```bash
cp Temp/Personal/all.txt Temp/A1/
```

#### 14. Удаление директорий с буквой `A` или цифрой `2`
```bash
# Безопасный способ через find (ищет только на первом уровне внутри Temp)
find Temp -maxdepth 1 -type d \( -name "*A*" -o -name "*2*" \) -exec rm -rf {} +
```
> 🔍 Проверьте, какие папки удалятся, перед запуском: замените `-exec rm -rf {} +` на `-print`

#### 15. Изменение строки приглашения (Prompt)
В bash за это отвечает переменная `PS1`. Выполните в терминале:
```bash
export PS1="ваш_шаблон"
```
**Примеры для вариантов:**
| Вариант | Команда в Git Bash |
|---------|-------------------|
| 1. Дата | `export PS1="[\d] \u@\h:\w\$ "` |
| 2. Каталог + `<` | `export PS1="[\w] < "` |
| 3. `\|` | `export PS1="\| "` |
| 4. Диск + пробел | `export PS1="[\w] "` (дисков в Linux нет) |
| 5. Версия ОС | `export PS1="[\$(uname -r)] \u@\h:\w\$ "` |
| 6. Дата и время | `export PS1="[\D{%d.%m.%Y %H:%M:%S}] \u@\h:\w\$ "` |
| 7. `<$>` | `export PS1="<\$> "` |
| 8. `\|\|\|` | `export PS1="\|\|\| "` |
| 9. Переход на новую строку | `export PS1="\n\u@\h:\w\$ "` |
| 10. Время в `$` | `export PS1="\$[\t]\$ "` |

# Контрольные вопросы

## Ответы на контрольные вопросы

### 1. Что такое командная строка?

**Командная строка** (command line, терминал, консоль) — это текстовый интерфейс для взаимодействия пользователя с операционной системой. В ней пользователь вводит команды с клавиатуры, а система выполняет их и выводит результат в текстовом виде. В Windows командная строка работает через интерпретатор команд `cmd.exe`.

---

### 2. Перечислите основные команды управления файлами в командной строке

Согласно таблице из лабораторной работы:

| Команда | Описание |
|---------|----------|
| `copy con <имя файла>` | Создание файла с консоли |
| `del <имя файла>` | Удаление файла |
| `ren <имя файла 1> <имя файла 2>` | Переименование файла |
| `edit <имя файла>` | Редактирование файла |
| `copy <путь 1> <путь 2>` | Копирование файла |
| `md <имя каталога>` | Создание каталога |
| `rd <имя каталога>` | Удаление каталога |
| `cd <путь>` | Переход в каталог |

---

### 3. Перечислите команды вывода основной информации системы

- **`prompt`** — изменение строки приглашения командной строки
- **`ver`** (не указана в таблице, но стандартная) — вывод версии ОС
- **`date`** и **`time`** — вывод/установка даты и времени
- **`hostname`** — имя компьютера
- **`systeminfo`** — подробная информация о системе

---

### 4. Перечислите команды ввода/вывода файлов

- **`type <имя файла>`** — вывод содержимого файла на экран
- **`copy con <имя файла>`** — ввод текста с консоли в файл (создание файла)
- **`edit <имя файла>`** — редактирование файла в текстовом редакторе
- **`dir`** (не указана, но основная) — вывод списка файлов каталога

---

### 5. Возможно ли полноценное управление системой, пользуясь только командной строкой? Ответ обоснуйте.

**Да, возможно.** Командная строка предоставляет доступ ко всем основным функциям операционной системы:

- ✅ Управление файлами и каталогами (создание, копирование, удаление, перемещение)
- ✅ Установка и удаление программ (через установщики в silent-режиме или PowerShell)
- ✅ Управление пользователями и правами доступа
- ✅ Настройка сети и системных параметров
- ✅ Запуск и завершение процессов
- ✅ Автоматизация задач через пакетные файлы (.bat, .cmd)

**Обоснование:** Графический интерфейс (GUI) — это лишь надстройка над системными вызовами. Все действия, выполняемые через GUI, можно выполнить через командную строку, часто даже более эффективно (особенно при автоматизации).

---

### 6. Подумайте, чем отличается командная строка Windows от командной строки MS-DOS, несмотря на их схожесть в командах

**Основные отличия:**

| Характеристика | MS-DOS | Windows Command Prompt |
|----------------|--------|----------------------|
| **Основа** | Самостоятельная ОС | Программа win32 (cmd.exe), работающая поверх Windows |
| **Файловая система** | FAT12/16 | NTFS, FAT32, exFAT и др. |
| **Доступ к ресурсам** | Прямой доступ к железу | Работает через API Windows |
| **Команды** | Базовый набор | Расширенный набор + поддержка PowerShell |
| **Многозадачность** | Однозадачная | Многозадачная среда |
| **Имя устройства** | 8.3 (короткие имена) | Поддержка длинных имён файлов |

**Несмотря на схожесть команд**, cmd.exe — это 32-битное (или 64-битное) приложение Windows, а не операционная система.

---

### 7. Приведите примеры интерпретаторов команд в других операционных системах

| ОС | Интерпретатор команд (оболочка) |
|----|--------------------------------|
| **Linux/Unix** | `bash` (Bourne Again Shell), `sh`, `zsh`, `ksh`, `csh` |
| **macOS** | `bash` (до macOS Catalina), `zsh` (по умолчанию с Catalina) |
| **FreeBSD/OpenBSD** | `tcsh`, `sh` |
| **MS-DOS** | `command.com` |
| **Windows (современная)** | `cmd.exe`, **PowerShell**, **Windows Terminal** |
| **OS/2** | `cmd.exe` |

**Наиболее популярные:**
- **bash** — стандарт для большинства Linux-дистрибутивов
- **PowerShell** — мощная оболочка от Microsoft с объектно-ориентированным подходом
- **zsh** — современная оболочка с расширенными возможностями (по умолчанию в macOS)

💡 Чтобы приглашение сохранялось после перезапуска Git Bash, добавьте выбранную строку `export PS1="..."` в файл `~/.bashrc` и выполните `source ~/.bashrc`.
