# Лабораторная работа №3  
## Диагностика работоспособности персональных компьютеров

---

### 🎯 Цель работы
Научиться проводить диагностику компьютера с помощью специализированных программ-диагностик для оценки работоспособности аппаратных компонентов и выявления потенциальных неисправностей.

---

### 📚 Теоретическая справка

#### 🔹 Зачем нужна диагностика ПК?
Программы для диагностики компьютера позволяют:
- ✅ Проверить конфигурацию системы (объём и использование памяти, типы накопителей, информацию о процессоре и т.д.)
- ✅ Оценить работоспособность устройств (жестких дисков, оперативной памяти, видеокарты, портов и др.)
- ✅ Выявить **«намечающиеся» дефекты** (например, bad-сектора на HDD из-за износа магнитной поверхности)
- ✅ **Предотвратить потерю данных** за счёт раннего обнаружения проблем
- ✅ Определить неисправности аппаратуры или ошибки конфигурирования системных файлов

#### 🔹 Объекты диагностики
Диагностика может выполняться:
| Уровень | Компоненты |
|---------|------------|
| 🖥️ Система в целом | Загрузка ЦП, общая стабильность, температурный режим |
| 🔧 Отдельные модули | Системная плата, оперативная память (стандартная/дополнительная/расширенная) |
| 🎮 Видеоподсистема | 2D/3D-рендеринг, разрешение, частота обновления |
| 💾 Накопители | Жесткие диски (HDD/SSD), CD/DVD/Blu-ray приводы |
| ⌨️ Устройства ввода | Клавиатура, мышь, тачпад, джойстики |
| 🔌 Порты и интерфейсы | Последовательные (COM), параллельные (LPT), USB, SCSI |
| 🌐 Сетевые компоненты | Сетевые адаптеры, Wi-Fi-модули |

---

### 🧰 Используемое ПО: PassMark BurnInTest

> **BurnInTest** — профессиональная утилита для стресс-тестирования и оценки надёжности ПК.

#### 🔹 Основные возможности:
| Функция | Описание |
|---------|----------|
| 🔥 Стресс-тест | Синхронная нагрузка на все подсистемы для проверки стабильности |
| ⚙️ Тестирование компонентов | CPU, RAM, HDD/SSD, GPU, звуковая карта, сеть, порты |
| 📊 Мониторинг в реальном времени | Температура, загрузка, ошибки, производительность |
| 📄 Генерация отчётов | Экспорт результатов в HTML, TXT, XML |
| 🔄 Гибкая настройка | Выбор длительности теста, циклов, интенсивности нагрузки |

#### 🔹 Преимущества:
- Поддержка многопоточного тестирования
- Возможность создания пользовательских профилей тестов
- Детальная статистика по каждому компоненту
- Автоматическое выявление и логирование ошибок

### 📋 Порядок выполнения работы

#### 🔧 Установка и запуск программы

1. **Найдите установочный файл**  
   В сетевой папке найдите и скопируйте файл:  
   `bitstd.exe`

2. **Установите BurnInTest**  
   - Запустите установщик от имени администратора  
   - Следуйте инструкциям мастера установки  
   - При необходимости выберите компоненты для установки

3. **Запустите программу**  
   - Откройте BurnInTest с ярлыка на рабочем столе или из меню «Пуск»  
   - Дождитесь полной загрузки интерфейса

---

#### 🧪 Проведение тестирования

4. **Выберите тип теста**  
   В верхней части окна программы найдите выпадающий список **`Quick Test`**.  
   В нём представлены предустановленные профили диагностики:

   | Профиль теста | Назначение |
   |---------------|------------|
   | `CPU Test` | Проверка стабильности и производительности процессора |
   | `Memory Test` | Тестирование оперативной памяти на ошибки |
   | `2D Graphics` | Проверка 2D-видеоподсистемы |
   | `3D Graphics` | Нагрузочный тест 3D-ускорителя |
   | `Disk Test` | Диагностика скорости и надёжности накопителей |
   | `Network Test` | Проверка сетевых интерфейсов |
   | `Full Test` | Комплексное тестирование всех компонентов |

5. **Выполните диагностику**  
   > **Задание:** Провести диагностику компьютера по **каждому** из предложенных видов теста.

   Для каждого теста:
   - Выберите профиль в списке `Quick Test`
   - Нажмите кнопку **`Start`** для запуска
   - Дождитесь завершения (или остановите вручную через 2–3 минуты)
   - Зафиксируйте результаты в таблице

---

### ❓ Контрольные вопросы

1. **Для чего необходимы программы для диагностики ПК?**  
   > *Ответ:* Для выявления аппаратных и программных неисправностей, оценки стабильности системы, профилактики сбоев и потери данных, а также для подготовки отчётности при техническом обслуживании.

2. **Назначение программы BurnInTest**  
   > *Ответ:* BurnInTest предназначена для стресс-тестирования и комплексной диагностики ПК: проверки стабильности работы компонентов под нагрузкой, выявления «слабых мест» и потенциальных отказов.

3. **Что такое тестирование?**  
   > *Ответ:* Тестирование — это процесс проверки работоспособности, производительности и надёжности системы или её компонентов путём выполнения контролируемых операций и анализа результатов.

4. **Виды тестирования программных продуктов**  
   > *Ответ:*  
   > - 🔹 **Функциональное** — проверка соответствия требованиям  
   > - 🔹 **Нагрузочное (стресс-тест)** — работа при пиковых нагрузках  
   > - 🔹 **Регрессионное** — проверка после внесения изменений  
   > - 🔹 **Диагностическое** — поиск и локализация неисправностей  
   > - 🔹 **Приёмочное** — подтверждение готовности к эксплуатации
