# Лабораторная работа №2  
## Оценка качества работы жесткого диска

---

### 🎯 Цель работы
Оценить качество работы жесткого диска с помощью специальных программных средств.

---

### 📚 Теоретическая справка

#### 🔹 CrystalDiskMark
> Небольшое приложение для измерения скорости записи и чтения накопителей.

**Ключевые особенности:**
- ✅ Поддержка тестирования с разными размерами блоков данных
- ✅ Возможность настройки количества циклов тестирования
- ✅ Выбор объёма данных для теста
- ✅ Одновременный запуск всех типов тестов
- ✅ Поддержка SSD, HDD, USB-накопителей

#### 🔹 CrystalDiskInfo
> Утилита для мониторинга состояния диска через технологию **S.M.A.R.T.** (Self-Monitoring, Analysis and Reporting Technology).

**Отслеживаемые параметры:**
| Параметр | Описание |
|----------|----------|
| 🌡️ Температура | Текущая температура диска |
| ⚠️ Проблемные сектора | Количество переназначенных/нестабильных секторов |
| 🔧 Ошибки позиционирования | Сбои при позиционировании считывающей головки |
| ⏱️ Время раскрутки | Время выхода диска на рабочую скорость |
| 📦 Версия прошивки | Актуальная версия firmware |
| ⏳ Наработка | Общее время работы устройства |

---

### 🧰 Оборудование и ПО
- Персональный компьютер с жестким диском (HDD/SSD)
- Программа **CrystalDiskMark** (для тестирования скорости)
- Программа **CrystalDiskInfo** (для диагностики состояния)

---

### 📋 Порядок выполнения работы

#### 📊 Часть 1. Тестирование скорости диска (CrystalDiskMark)

1. **Установите программу CrystalDiskMark**  
   - Скачайте актуальную версию с официального сайта: [crystalmark.info](https://crystalmark.info)
   - Запустите установщик и следуйте инструкциям мастера установки

2. **Запустите программу**  
   - Откройте CrystalDiskMark от имени администратора (рекомендуется)

3. **Настройте параметры теста**  
   | Параметр | Значение |
   |----------|----------|
   | Количество запусков тестов | `6` |
   | Объем тестируемых данных | `1000 MiB` |
   | Целевой диск | Выберите нужный раздел из выпадающего списка |

4. **Запустите тестирование**  
   - Нажмите кнопку **`All`** для одновременного запуска всех тестов  
   - Дождитесь завершения процесса (индикатор прогресса заполнится)

5. **Заполните таблицу результатов**

| Вид теста | Чтение (МБ/с) | Запись (МБ/с) |
|-----------|---------------|---------------|
| SEQ1M Q8T1 |  |  |
| SEQ1M Q1T1 |  |  |
| RND4K Q32T16 |  |  |
| RND4K Q1T1 |  |  |

> 💡 *Расшифровка обозначений:*  
> - **SEQ** — последовательное чтение/запись (большие файлы)  
> - **RND** — случайное чтение/запись (мелкие файлы, 4K)  
> - **Q** — глубина очереди (Queue depth)  
> - **T** — количество потоков (Threads)

---

#### 🔍 Часть 2. Диагностика состояния диска (CrystalDiskInfo)

6. **Установите и запустите CrystalDiskInfo**  
   - Скачайте утилиту с официального сайта  
   - Запустите программу (установка не обязательна — доступна Portable-версия)

7. **Зафиксируйте ключевые параметры диска**  
   Запишите в тетрадь/отчёт следующие данные:

| Параметр | Значение | Примечание |
|----------|----------|------------|
| 🌡️ Температура |  | Норма: 30–50 °C |
| 🟢 Техническое состояние |  | "Хорошо", "Тревога", "Плохо" |
| 🔁 Число включений |  | Количество циклов питания |
| ⏱️ Общее время работы |  | В часах (Power-On Hours) |
| 🌀 Скорость вращения |  | Только для HDD (например, 5400/7200 RPM) |
| 📋 Модель диска |  | Полное название устройства |
| 🔖 Серийный номер |  | Уникальный идентификатор |

---

### 📝 Оформление отчёта

Отчет должен содержать:
1. Титульный лист (ФИО, группа, дата, тема работы)
2. Цель работы
3. Заполненную таблицу результатов CrystalDiskMark
4. Скриншот главного окна CrystalDiskInfo с выделенными параметрами
5. Таблицу с зафиксированными параметрами диска
6. **Вывод**:  
   - Оценка производительности диска (соответствие заявленным характеристикам)  
   - Оценка технического состояния (на основе S.M.A.R.T.)  
   - Рекомендации по дальнейшей эксплуатации (при необходимости)

### ❓ Контрольные вопросы

1. В чём разница между последовательным и случайным доступом к данным на диске?

 > Последовательный доступ — это чтение или запись данных, расположенных подряд на диске
 > Случайный доступ — это обращение к данным, разбросанным по разным участкам диска

2. Что означает аббревиатура S.M.A.R.T. и какие критические атрибуты она отслеживает?

 > S.M.A.R.T. - Self-Monitoring, Analysis and Reporting Technology — технология самодиагностики, анализа и отчётности, встроенная в накопители.
 > Артибуты:
 05 - Reallocated Sectors Count
 C5 - Current Pending Sector Count
 C6 -	Uncorrectable Sector Count
 01 - Raw Read Error Rate
 07 - Seek Error Rate
 C4 - Reallocation Event Count
 03 - Spin-Up Time
 
3. Почему результаты тестов CrystalDiskMark могут отличаться при повторных запусках?
4. Какие признаки указывают на скорый выход жесткого диска из строя?
5. Как влияет температура диска на его производительность и срок службы?
