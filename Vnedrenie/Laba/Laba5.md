# Лабораторная работа №5  
## Тестирование качества монитора с помощью программных средств

### Цель
> Провести диагностику монитора и выбрать оптимальные параметры цветового отображения.

---

## Теоретические сведения

**MonitorTest** — утилита от разработчиков **PassMark Software**, которая позволяет производить различные тестирования монитора.

### Возможности программы:

| Функция | Описание |
|---------|----------|
| 🖥️ Разрешение | Поддержка всех доступных разрешений и глубины цвета |
| 🔆 Контрастность | Анализ уровня контраста изображения |
| 🎨 Цветопередача | Анализ точности отображения цветов |
| 🔤 Шрифты | Проверка чёткости отображения текста |
| 💻 Совместимость | Поддержка большинства типов мониторов |
| 👆 Multitouch | Тест экранов с мультитач-поддержкой |
| 📐 Конвергенция | Проверка сведения цветовых лучей |
| ⚙️ Видеокарты | Поддержка более 300 режимов работы видеокарт |

### 3. Цветовые тесты (вкладка *Test Config* → *Select Test Type*)

#### 🔹 Тесты Scale: Black, Red, Green, Blue, White
> **Критерии оценки:**
> - Яркость цвета на всём экране должна быть **одинаковой**, без тёмных и светлых пятен
> - Тесты полезны для поиска **«битых» пикселей** на LCD-мониторах
> - Оцените влияние **угла обзора** на восприятие цвета
> - Видим ли плавный переход от чёрного к: 🔴 красному, 🟢 зелёному, 🔵 синему, ⚪ белому?
